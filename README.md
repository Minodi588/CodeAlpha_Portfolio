# 💼 Personal Portfolio Website | CodeAlpha

A modern, responsive, and interactive **Personal Portfolio Website** built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship – Task 3**.

## 📌 Project Description

This project is a personal portfolio website designed to showcase my skills, projects, experience, resume, and contact information in a clean and professional layout.

The website is fully responsive and includes smooth scrolling, animations, interactive hover effects, and a mobile-friendly navigation experience.

## ✨ Features

* 👩‍💻 About Me section
* 🛠️ Skills section
* 💼 Projects showcase
* 📄 Resume section
* 📧 Contact section
* 🔗 Social media and professional profile links
* 📱 Responsive design
* 🖱️ Interactive hover effects
* ✨ Smooth animations and transitions
* 🧭 Smooth scrolling navigation
* 📱 Mobile-friendly layout
* 🎨 Clean and modern user interface

## 🛠️ Technologies Used

* **HTML5** – Used to structure the portfolio website and its sections.
* **CSS3** – Used for styling, responsive layouts, animations, transitions, and hover effects.
* **JavaScript** – Used to add interactivity and enhance the user experience.

## 🚀 How to Run the Project

### Method 1 – Open Directly

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the portfolio website.

### Method 2 – Using Visual Studio Code

1. Open the project folder in **Visual Studio Code**.
2. Open `index.html`.
3. Run the project using a browser or the **Live Server** extension.
4. View and interact with the portfolio website.
